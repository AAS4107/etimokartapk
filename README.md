# Etimokart (Android)

Bu depoyu GitHub'a yükle -> Actions -> "APK derle" -> Run workflow.
Bitince Artifacts bölümünden `etimokart-apk` dosyasını indir.

Bilgisayarda denemek için: `pip install kivy certifi` ve `python main.py`


## Sunucu
Oyun artık Raspberry Pi sunucusuna bağlanır. Adres `api.py` içindeki `API_URL` satırındadır (varsayılan https://api.etimokart.com.tr). Kendi adresini yazıp yeniden derle.
